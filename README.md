# Ainsley Weaver's Research for Milestone
This repository consists of my research on Python. My group discussed potentially using Python for our app, and I haven't used it in years so I thought I would give it a try.
To start and get familiar with the language, I followed a [Geeks For Geeks tutorial](https://www.geeksforgeeks.org/python/make-simple-calculator-using-python/) on making a basic calculator app. I had never used Tkinter before, so it was interesting seeing how it worked.

After setting up the environment and playing around with it, my next step was to actually go through and research the basic syntax for the language. For this section, I read up on the official [Python Language Reference](https://docs.python.org/3/reference/index.html) and [W3Schools' basic Python tutorial](https://www.w3schools.com/python/python_syntax.asp).
